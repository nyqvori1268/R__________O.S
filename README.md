v2.1.11 更新內容
- 新增「塔之守護者／無盡之塔（單次挑戰）」模式，挑戰結束後自動停止，不重複進場，也不因技能配置而重開。
- 塔用技能與強化點數由玩家在入場前自行設定，工具不會更改配置或自動花費點數。
- 塔內自動選擇開場神祇與每層強化卡，依血量、回血續航、減傷、控場及清怪／頭目時限估算效益，並在紀錄中顯示選卡理由。
- 原技能排序作為同分參考，優先避開 ❌；若所有選項都已排除，會使用備援選卡繼續挑戰。
- 塔內保留避險走位，停用一般副本的開場站定、湊錢開箱與承傷拾取規則。
- 新增樓層、HP 與本層分數顯示；已有儲存挑戰時，由玩家自行決定繼續或開始新挑戰。


v2.1.10 更新內容
- 將承傷拾取設定下方改為五個標籤頁，依序為：出征&難度、技能配置、本局道具、神祇、備份與紀錄。
- 將「神祇」從本局道具區獨立成頁，保留原本的排序、❌ 排除及單人／組隊設定。
- 切換分頁時保留清單與捲動位置，未顯示的分頁仍會持續同步技能及道具。
- 支援滑鼠切換；聚焦標籤後，可使用左右方向鍵、Home、End 操作。窄版面板支援橫向捲動標籤。
